# ungungnam.github.io

Personal homepage, served by GitHub Pages from `main`.

- `index.html` — the whole site (plain HTML, no Jekyll templating)
- `cv.pdf` — CV, linked from the homepage. Authored in Overleaf; the LaTeX
  source lives there, not in this repo. To update, download the compiled PDF
  from Overleaf and replace this file.
- `images/` — profile photo and publication thumbnails
